## Phase 2b — Second research pass ✅ (2026-09-17)

**Methodology breakthrough:** Phase 2a's conclusion that primary sources were unreachable was too pessimistic. **WITS (World Bank, mirroring UN Comtrade) is fetchable** via a plain URL and returns per-country USD values *and* quantities. The catch is that WITS uses legacy **HS1992** codes, so current HS2017/2022 subdivided codes 404 — map back to the legacy parent (cumin `090930` not 0909.31, groundnuts `120220` not 1202.42, etc.). Full URL pattern and mapping table in `research/unverified.md`. This lifted the dataset from 9 products to **29**, at a materially better source tier. Future sessions must try WITS before concluding data is unavailable.

**Delivered:**
- **20 new trade-data JSON files** (29 total) — turmeric, red chilli, cumin, black pepper, coriander, cardamom, chickpeas, lentils/masoor, guar gum, groundnut kernels, psyllium, maize, fish meal, squid/cuttlefish, ginger, garlic, mango, dehydrated onion, rice bran/DORB, other oilcake/neem cake. All WITS/UN Comtrade calendar-2024, retrieved 2026-09-17, each with its own confidence caveat in `notes`.

These must not have their totals presented as product-specific.
- **8 HS codes corrected** in `_data/hsCodes.json`, two of them genuine errors: rapeseed/mustard meal `2306.30 → 2306.49` (2306.30 is *sunflower*, confirmed via WITS's own label) and neem cake `2306.50 → 2306.90` (2306.50 is *coconut/copra*).
